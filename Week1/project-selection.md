## 2. Selected Projects

### Project 1: Dockerize an Application

**Project:** Dockerized 3-Tier Application Deployment on AWS

**Technologies:**

* Linux
* Git & GitHub
* Docker
* Docker Compose
* Nginx
* AWS EC2
* AWS RDS
* Shell Scripting

**Project Overview:**

This project implements a containerized three-tier application consisting of a frontend, backend API, and MySQL database. Docker and Docker Compose are used for containerization and service management, while Nginx is used as a reverse proxy. The application is deployed on AWS using EC2 and RDS.

This project has already been developed and will be reviewed and enhanced during the internship to align with the requirements of the selected Docker project, including Dockerfile practices, Docker Compose, and image optimization.

### Project 2: CI/CD Pipeline

**Project:** CI/CD Pipeline for the Dockerized Application

**Technologies:**

* Git & GitHub
* GitHub Actions
* Docker
* Docker Compose
* Shell Scripting
* AWS EC2

**Project Overview:**

The second project will focus on implementing a CI/CD pipeline for the Dockerized application. The pipeline will automate important stages of the software delivery process, including source-code checkout, testing, Docker image building, and deployment.

The objective is to create a practical multi-stage CI/CD workflow that demonstrates automated testing, build processes, deployment triggers, and reliable application delivery.
